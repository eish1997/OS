# ADR-027 本地文档阅读与草稿预览

日期：2026-10-07。状态：已实现，工程验证与浏览器验收分别记录。关联L-01b、M0-05/06；沿用Factory + ASCII（旧文档已移除，参见 Git 历史）。

## 决策

复用react-markdown 10.1.0和remark-gfm 4.0.1（MIT），锁定依赖，不自行实现Markdown解析器。安装使用ignore-scripts，不执行新依赖生命周期脚本。依据[react-markdown官方文档](https://github.com/remarkjs/react-markdown)和[remark-gfm官方文档](https://github.com/remarkjs/remark-gfm)，采用React元素渲染，不启用raw HTML插件或dangerouslySetInnerHTML。

Markdown资产默认为浅色纸面阅读，保留原文切换和原文件下载；草稿提供编辑/预览，预览读取本机当前修改，不修改正文或导出契约。显示标题、列表、表格、引用、代码块和脚注；表格/代码块允许局部滚动，正文保持中文阅读行宽。超过128Ki字符时显示完整原文，避免生成过大语法树，不截断或改写资产。

文档中的HTTP/HTTPS链接由用户点击打开，HTML仅显示为文字；图片显示说明与查看链接，不自动请求远程图片。相对路径和未知协议不创建可执行链接，暂未实现工作台文件引用解析，不宣称支持。脚注使用每个阅读实例独立的ID前缀。

文本、JSON/XML等明确文本MIME可以读取；PDF等未支持格式提供原文件下载，避免显示二进制乱码。加载、失败和空内容分别显示。请求沿用取消及请求序号检查，迟到结果不能覆盖当前资产。

同名草稿以列表编号、创建时间、ID片段和正文摘要区分；摘要反映本机修改。来源按当前项目和ready资产核对，展示名称/版本/hash并打开相应成果视图；缺失或其他项目来源显示暂不可用。跳转前保存当前修改，保存失败/冲突时留在草稿，保留修改与错误状态，不将未保存内容当成已保存。

## 验证边界

服务端React渲染测试覆盖中文/CRLF/GFM、HTML与URL约束、远程图片不自动加载、长文完整性、加载/错误/未知格式、同名草稿识别和来源作用域。它们验证渲染输出，不替代真实浏览器中的切换、自动保存、滚动、焦点、来源跳转和尺寸验收。046历史交互证据保留，新增行为仍需本地实际页面复核。
