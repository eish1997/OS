# 我想让个人 AI 工作台记住什么？从腾讯 Memory 开始验证

状态：资料审阅初稿；没有性能测试或运行效果结论。正式发布前须补充实际实验、修改未验证描述。

我正在搭建一个个人 AI 工作台。项目多了之后，最容易重复的工作是重新解释：这个项目为什么选 Pi、界面要什么风格、哪些决定已经确定、哪些只是候选。

因此，我选择腾讯开源的 TencentDB Agent Memory 作为第一个验证对象。目标不是装好一个服务就算成功，而是回答：它能否让助手跨会话准确找回背景，同时让人查看来源、纠正错误和撤回记忆？

固定版本的官方资料描述了对话记忆、技能、文档知识和代码关系等资产，并给出了 Memory Core、Hub 和 Proxy 的组合部署路线。环境模板的单机默认存储是 SQLite；记忆处理与上游生成使用分别的模型配置。[固定版本安装说明](https://github.com/TencentCloud/TencentDB-Agent-Memory/blob/8b86874a2daea49e3ff0fb53d699203146c5c77d/INSTALL_CN.md)

对我的工作台来说，这意味着需要验证的不只是“能记住”，还包括后台提取费用、项目范围、技能是否经过验证，以及删除之后检索和缓存是否真的停止返回旧内容。官方展示的客户端接入路线也不能直接证明 Pi 已兼容。

我准备了七类测试：跨会话召回、确认状态、纠正、项目隔离、停用和删除、不可信资料、故障与退出。每类三个合成案例，先冻结问题和预期，再记录真实结果。对比时使用同一个模型，并把记忆提取费用算入总成本。

目前完成的是工作台工程与资料准备，腾讯服务实验还没有运行。我不会把成功启动、漂亮界面或一次自评分当成有效记忆的证明。后续报告会逐例展示来源、结果和失败，再决定接入还是暂缓。

我的期待很具体：下次打开一个项目，助手能接上经过确认的背景；当我改变想法，它能用新决定；当我删除内容，它不再把旧信息当作当前事实。
