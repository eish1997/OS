# ADR-031 草稿修改后的重试接续

日期：2026-10-07。状态：实现、隔离服务/联合恢复测试和154项完整工程通过，已正常应用主服务；[055真实Pi重试](../dev/iterations/055-real-draft-retry.md)通过，实际浏览器交互仍待验收。

问题：Task保存最初选中的稿件版本，而旧boundDraft只读取当前Run的更新回执。先前尝试将草稿1→2后取消或失败，重试的新Run仍读版本1，不能继续保存版本2；既有版本保护正确拒绝了这次写入，但接续闭环不完整。

决定：保留Task原始输入不变。读取当前尝试及其明确parentRunId祖先的已完成宿主draft-update回执，恢复本任务已经保存的稿件版本和来源。校验同任务/项目、连续attempt、可重试终态、中断已对账、链无循环且原始尝试存在；祖先有started/unknown操作时停止接续。回执版本须从原始绑定逐版连续。

不从当前数据库的最新稿件、原生聊天记录、其他任务或兄弟尝试推导覆盖权限。普通user-confirmed人工对账结果不是宿主草稿更新回执。当前Run仍须通过当前工具许可、超时、取消及版本检查。用户后来手动修改时，读取已确认的任务版本并提示发生变化，保存拒绝覆盖；用户重新查看并发送新任务才能绑定该版本。

更新仍使用ADR-029中的原子事务与操作幂等，新Run只登记自己的新成果；旧Run回执保留，不重放已经完成的写入。无新增schema或凭据迁移。Pi工具说明明确重试先读取已确认版本，再继续目标。

隔离复现、六类新增测试及部署/验证事实见[054](../dev/iterations/054-draft-retry-receipts.md)。服务测试包括取消/失败/已对账中断、多轮接续、来源、干净联合恢复、手动编辑、兄弟尝试/其他任务、异常接续链和未知回执。工程测试不替代浏览器或真实模型重试证据，M0仍待验收。
