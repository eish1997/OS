# 089：目录替换前的项目预检

2026-10-16，EMB-04继续。未部署、推送或模型调用。

## 实现

目录重定位和文件替换不再直接转发。预览成功后，确认令牌只属于发起它的项目；其他项目拿不到确认。重定位结果里的画板必须就是当前目录的画板，目标路径若已被其他项目登记则拒绝。

替换预览会带上需要保留的子目录画板。该画板属于其他项目时，预览直接拒绝，不会进入确认。尚未归属的子目录预留给当前项目。确认前再次核对子目录仍属于当前项目。

## 验证

`tests/canvas-resources.test.ts` 通过：B 不能预览或确认 A 的目录重定位；A 可以完成重定位。子目录替换预览返回原来的子画板，B 不能确认该令牌。把子画板改记到 B 之后，A 的下一次替换预览返回 403。原项目 API 测试、本地替换测试和根类型检查通过。
