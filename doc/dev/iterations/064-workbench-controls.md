# 064：统一工作台控件

用户截图暴露了三个问题：系统原生下拉选项不跟随主题；窗口列表和布局菜单的圆角、背景、阴影不一致；打开新弹层后旧菜单仍停留。

## 实现

- `controls.tsx` 提供主题 Select、输入/确认弹窗和工具栏弹层关闭行为；项目、已有对话、资料目标聊天复用选择组件。
- 新建空间/项目、重命名、副本命名、删除空间、重载冲突和关闭有未保存输入的窗口，使用应用内对话框替代浏览器 prompt/confirm。
- 控件样式集中在 `controls.css`，继承四套主题与全局线宽；统一按钮、弹窗、菜单行与焦点状态。
- 布局与窗口列表互斥；菜单动作执行后关闭；外部点击关闭；选择框支持方向键、Home/End、Enter、Esc、前缀定位，长列表滚动并限制视口位置。

## 验证

类型检查、构建、原窗口/资产/聊天浏览器回归、布局回归和外观回归。新增 `scripts/workbench-controls-qa.ts` 覆盖30项目、浮层互斥、分层Esc、输入取消、新建项目、深浅主题、3px边框及800×600视口。布局回归含100次混合操作、保存故障恢复、多浏览器冲突、服务重启和真实150%缩放。

证据：`output/dev-evidence/workbench-ui-064/`。隔离数据运行测试，不调用模型；真实本地入口另作只读验收。范围是新版工作台；旧版界面保留原样。
