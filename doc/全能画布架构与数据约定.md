# 全能画布架构与数据约定

更新：2026-10-15。状态：重构实施约定，尚未完成运行验证。

产品行为以[需求与验收](全能画布需求文档.md)为准，任务顺序见[开发执行文档](开发执行文档.md)，实际进度只记在[开发现场](dev/current.md)。代码建立后，具体字段类型与接口签名以代码为准；本文维护语义与约束。

## 1 已定方向与实施默认

使用 OpenPencil 完整编辑体系作为底座，固定来源提交、运行原版后再扩展。不因旧 OS 使用 React 而重写其编辑器。先交付独立、本机可用的画布资产管理器，再接入重构 OS。第一验证平台是当前 Windows 环境，其他平台逐项验证。

保留现有 OS 代码、数据、账号、会话和备份能力。开发使用独立配置和样例目录，不直接迁移真实数据。推荐在 OS 仓库内建立独立应用目录；确切目录、构建命令及宿主框架在 C00/C01 验证后固定。

以下是可调整的工程默认，并非用户已确认的细节：加目录只关联、不搬动；子目录先显示文件夹节点，打开后有自己的画布；默认落盘到当前关联目录；移除节点不删除磁盘原件；个人节点库先行；基本浏览编辑不依赖模型联网。删除原件、覆盖成果与公开分发必须具有明确操作语义。

## 2 模块分工与权威数据

| 模块 | 职责 |
| --- | --- |
| OpenPencil 编辑核心与适配层 | 场景、视口、选择、几何、图层、编辑命令、撤销 |
| 本地工作区服务 | 挂载、文件索引、工作内容、保存事务、恢复 |
| 节点运行服务 | 类型、版本、隔离实例、能力调用、错误与资源回收 |
| 任务与 agent 桥接 | 输入快照、任务状态、生成代码、输出关联 |
| 桌面宿主 | 窗口、快捷键、网页承载、系统文件访问 |
| 后续 OS 适配层 | 项目、会话、资产、任务关联，保持画布可独立运行 |

上游编辑文档是几何和编辑属性的唯一权威；目录与内容存储管理素材事实。适配层用稳定 ID 连接，不能另建竞争的场景树。索引、缩略图和缓存必须能重建。来自不同模块的内容共用坐标、选区、快捷键和编辑历史。

### 2.1 全窗口画布与工作台窗口管理

应用内容区自下而上分为连续画布层、停靠/普通浮窗层、应用内置顶窗口与图标层、必要菜单及模态层。具体渲染机制待原型验证，但画布视口始终覆盖整个内容区；停靠区是覆盖在画布之上的工具布局，不占据画布作品空间。视觉规范遵循 [design.md](design.md)。

窗口管理器负责分割树、停靠位置、浮窗矩形、图标化、层级和焦点；编辑器负责作品。面板使用窗口坐标，节点使用画布世界坐标，经统一变换换算。调整面板不得改节点坐标或文档撤销；画布平移缩放不得移动面板。遮挡与可见区域可用于渲染优化，但不能改变作品几何。

只有实际面板、图标和拖拽柄捕获对应输入，空白覆盖层将输入交给底层画布；面板内部滚动、键盘及拖拽不误触画布。网页等原生视图需验证是否能正确参与遮挡与焦点。应用内点到画布与穿透给操作系统桌面是两个独立机制。

布局持久化单独管理 LayoutPreset（ID、名称、格式版本、分割方向/比例、面板 ID 与类型、停靠位置、浮窗矩形、图标位置、置顶顺序）及当前布局。业务面板状态通过稳定实例 ID 引用，不把任务或未提交输入仅存在布局文件中。恢复时处理窗口尺寸变化、越界和缺失面板类型，保留可找回入口；损坏布局可回退默认，不能清理画布数据。保存配置的作用域暂按本机工作台默认，是否按项目/画布覆盖后续细化。

首版只验证全窗口画布与少量覆盖面板的契约，完整窗口管理器在 C11.1 实现，OS 业务桥接在 C11.2 实现。首期格式为独立布局配置留版本边界，不预先实现整套工作台。

## 3 最小数据模型

| 对象 | 必须表达的内容 |
| --- | --- |
| Mount 挂载目录 | 稳定 ID、本机路径、可用状态、扫描范围 |
| Canvas 画布 | 稳定 ID、目录关联、格式版本、场景快照、视图设置 |
| Node 节点 | 稳定 ID、类型及版本、配置、几何、内容引用 |
| Asset 内容 | 稳定 ID、类型、修订号、来源；可被多个节点引用 |
| FileLink 文件关联 | 挂载 ID、相对路径、系统可用身份线索、上次观察到的修订 |
| WorkBlob 工作内容 | 应用管理区的持久化内容引用、校验信息 |
| NodeType 节点类型 | 类型 ID、版本、入口、能力、配置版本、迁移规则 |
| Task 任务 | ID、输入修订快照、状态、输出、错误、恢复规则 |
| Operation 操作 | ID、执行阶段、预期修订、结果，用于重试去重和恢复 |

C00 已验证当前 OpenPencil FIG 往返会重写节点 ID，见[基线证据](../output/dev-evidence/canvas-c00/README.md)。因此不能直接将 FIG 节点 ID 用作文件关联的持久业务身份；C02 须验证可保留稳定身份的原生场景快照或显式映射。

C02 当前实现：普通节点身份保存在 `os.canvas/nodeId` 元数据中；复制/粘贴生成独立 UUID，撤销/重做保留同一节点的身份。页面元数据在当前 FIG 往返中丢失，因此同次事务的作品元数据另外保存页面身份与名称的有序清单；打开同一快照时校验数量、名称顺序及身份冲突再恢复。该顺序仅是快照内的映射依据，不是跨修订的业务身份。视口保存当前页面 UUID、平移与缩放，不保存重开后失效的 FIG 内部 ID。证据见 [C02 身份恢复](../output/dev-evidence/canvas-c02/identity-persistence.json)。

文件名、路径和内容哈希都不能单独充当身份。同内容文件可独立存在，同一文件修改后不应自动成为新节点。复制节点生成新节点 ID，可引用同一素材；共享编辑与创建内容副本须在操作中明确。

默认一个规范化目录关联一个主画布。检测大小写、链接、重复和嵌套挂载，不能只比较路径字符串；无法可靠判断目录别名时明确提示。扫描不得无限跟随链接或越过指定范围。

## 4 保存、同步与恢复

应用管理区保存场景、工作内容、日志、节点包和索引；用户目录保存正式文件。未导出的工作内容也必须持久化，不能只放浏览器缓存。默认采用本机元数据数据库加内容文件，具体实现和上游序列化方式在 C02 固定。

C02 固定格式 1：workspace.sqlite 保存画布 UUID、顺序修订、FIG 内容 SHA256、元数据、操作 ID 与请求摘要；scenes/{SHA256}.fig 保存不可变快照，文字和内嵌图片本体随 FIG 保存。元数据为 formatVersion、name、pages（稳定 UUID/名称）与 view（页面 UUID、平移/缩放），同版本未知字段原样保留。layout.sqlite 使用独立 schema/格式 1，仅保存首期面板可见性，布局不产生作品修订。历史恢复追加新修订；不覆盖旧场景。这里的内容文件承担首期 WorkBlob 的持久引用/校验职责，素材独立身份和文件关联在 C03/C04 引入，节点包依赖在 C08 引入；新增格式必须继续满足未知数据保留及迁移前保留副本约束。

沿用上游格式或建立可无损往返的扩展格式，保留未知节点数据。场景文件和数据库不一定共享原子事务，必须以修订、日志和启动恢复协调。界面区分正在保存、已保存、失败和未导出。异常退出后已确认保存的内容必须恢复；未确认输入的损失边界需实测。

C05 作品包格式 1 使用 OSCANVAS1 头与压缩清单，包含全量历史、按摘要去重的 FIG 本体、布局与外部文件引用；外部原件不打包。导入包不授予原路径访问身份：保留引用 ID，但目录与文件须经本机检查及明确重新关联才视为可用。普通作品包不收集应用凭据。

导入通过 package-imports.sqlite 保存原始包、摘要、操作 ID 和 prepared/complete 状态；目录、索引、作品历史及布局各自以同操作 ID 幂等提交，跨库不是共同原子事务。进程中断后从持久原包向前恢复，不删除已提交内容、不重复应用旧状态。已知目标冲突在准备阶段拒绝；后续冲突保留日志供恢复，不能假报完成。布局导入作为独立预设保留，仅未保存过布局的新管理区自动应用；已有布局保留，界面后续提供明确的应用入口。该格式及后端已进入实现，完整界面与迁移验收状态以现场为准。

目录监听加启动/手动补扫发现外部变化。删除或离线保留节点及布局，显示缺失。重命名优先依据可靠系统身份；证据不足时要求重新关联，不按同名或同哈希静默合并。外部更新与画布待保存修改冲突时保留双方。

### 成果落盘事务

1. 获取节点、内容修订、操作 ID，检查支持的导出格式。网页、工具和组合节点只提供明确支持的快照、文件或节点包格式。
2. 确定目录和名称，检查重名、权限、离线和路径范围。默认不覆盖，另存或覆盖由明确操作决定。
3. 写同目录临时文件并校验，再按平台支持方式提交目标文件；记录日志。跨文件系统操作不能假定原子。
4. 更新文件关联与修订，保持原节点身份、位置和选择。扫描识别本次操作，不重复生成节点。
5. 启动恢复检查日志和磁盘事实：文件已提交但关联未完成则补关联；写入未完成则保留工作内容供重试。

当前成果日志 `outputs.sqlite` 为 schema 3，升级前保留一致性备份。临时文件在写入前登记操作与打开句柄的文件身份，取消/完成后及目录扫描时按身份和内容校验补清理；活跃写入不清理，无法证明归属的旧残留保留。清理不删除成果或用户原件，清理失败不推翻已提交状态。

当前文件发布优先使用同目录硬链接；Windows 不支持硬链接时通过系统 `MoveFileExW` 在同目录移动，不启用覆盖或跨卷复制。两条路径均校验日志文件身份与内容，支持目标已存在但日志未提交时恢复。没有可用安全方式则明确失败并保留快照，不用覆盖复制掩盖错误；未实测卷不能宣称兼容。

成果来源保留原导出快照的摘要和格式（snapshotHash/snapshotFormat），来自持久日志，不随磁盘文件外部编辑而改写。判断“尚未重新导出”须比较对应来源节点的当前输出内容：TXT 比较文字字节，PNG 比较导出图片；不能仅用整张画布修订号判断，移动节点或编辑其他对象不必然改变成果。旧元数据缺少摘要或当前无法比较时显示未核对，不假定一致。多份成果各自比较；当前内容与原导出快照一致也不表示磁盘文件未被外部修改。异步比较结果必须核对画布、选区及内容是否已变化，不能覆盖较新的状态。

同一操作重试返回已有结果，不重复生成文件。同一节点多次输出保留主要文件关联，将其余成果记为附加文件关联；全部关联随作品保存并参与扫描更新，不为同一原节点重复创建成果卡片。重新关联主要文件不隐式移除其他成果；外部删除成果保留原节点及缺失关联。当前元数据分别为 `os.canvas/fileLink` 与 `os.canvas/outputLinks`。批量保存逐项报告；各项固定已保存的来源修订与输出快照，失败项不阻断后续项，重试保留原操作 ID 和原内容且不重交成功项。当前首期命名按输入文件名添加序号，单项冲突不自动覆盖或改名。必须测试磁盘满、写保护、同名竞争、写入中断及文件提交后中断。普通画布撤销不能暗中删除导出文件、回滚原件或重复收费任务；文件副作用提供独立恢复方式。

## 5 编辑、筛选与宿主接口

筛选只影响视图。默认同字段多值为“或”，不同字段为“且”；隐藏端点的连线一并隐藏，显示隐藏数量。清除后布局恢复；隐藏不删除内容、不取消任务。组与嵌套对象规则在 C05 固定。

首期展示单元是当前页顶层对象。分组/画框任一实际内容节点同时匹配类型、关联及查询条件时，保留整个子树；文件卡片的自动文件名标签不算独立文字内容。查询匹配节点名称或关联路径，文件类型按扩展名分类不代表对应格式已有预览器。筛选排除集只存在运行时视图中，不写入节点 visible、几何、文件、撤销历史或导出副本；绘制、命中、选区和关联标识共用排除规则，切换条件清理隐藏选区。首期条件随标签会话存在，重开默认全部内容；保存常用视图及新媒体/节点状态在后续阶段扩展。连线端点协议引入后必须补同一视图规则的集成验收。

所有写入经统一命令，携带操作 ID，更新时校验预期修订。长任务固定输入版本，输出先作为独立工作成果，不能覆盖用户后续修改。状态区分排队、运行、成功、失败、取消和中断；重启后不自动重发可能收费或有外部副作用的任务。

宿主接口至少覆盖：加入目录、打开画布、查询资产、读取内容、执行编辑命令、保存文档、导出内容、启动/取消任务、安装/加载节点版本、订阅变更。独立应用和 OS 使用同一语义。错误区分不存在、离线、冲突、无权限、不支持格式、取消和内部故障。

## 6 节点与 agent 边界

内容、工具、交互是可组合能力。节点包声明身份、版本、入口、输入输出、配置结构、依赖、能力和迁移。可执行代码不能作为普通场景数据直接求值。

生成节点先进入草稿，隔离运行并显示真实实例；修改保留测试输入。正式版本不可原地改写，实例固定版本；升级迁移副本并验证，失败保留旧配置。缺失、停用或卸载包时保留占位及原数据。本机发布与公开上传分开。

隔离必须支持终止死循环与资源回收。try/catch、动态 import 或组件错误边界不等于隔离。生成代码经声明的能力访问宿主，文件限定范围，网络/进程另行声明，不能获得宿主令牌。可信内置模块与生成模块不共用无限权限。

C01.2 当前执行原型采用每实例独立 Node Worker 内的 QuickJS WASM 运行时。生成代码仅在解释器内执行，通过 JSON 交换结果；宿主负责可信界面呈现。Worker 路径、引擎和允许读取的素材由可信服务配置，不从节点请求中接受；本地服务认证后提供运行、状态查询及取消接口，默认关闭。当前 CPU 中断、墙钟终止、取消、并发上限与私有管道退出回收均有执行层证据；堆/栈设置不等于已证明整体进程内存上界。

此方案目前只验证同步脚本和文本视图，不能将它当成最终三类节点的全部承载方式。异步能力、动态素材授权、自定义交互界面与媒体渲染、节点草稿持久化和版本迁移仍需 C08 设计与实测。原生验证包使用独立应用身份和显式编译开关；同步文本节点的运行、取消、错误恢复及画布响应已通过真实 Tauri 窗口验证，证据见 output/dev-evidence/canvas-c01/isolation。该结果不覆盖上述仍待 C08 验证的能力。

agent 创建、修改、测试、发布走同一协议并返回真实日志。模拟模型只验证协议；真实服务不可用时记录阻塞，不据此宣布对话开发通过，也不重置既有账号。

## 7 网页与透明桌面

网页节点需验证网站限制、登录、输入法、滚动、焦点、缩放、遮挡及资源释放；不假设 iframe 能浏览所有网站。网页会话与 agent 凭据分开，不进入画布导出包。记录支持的网站测试范围。

C01.3 原型已实测 Windows/Tauri 子 WebView 会覆盖主页面中最高 CSS 层级的面板（证据 canvas-c01/web/native-overlap.png 与 native-hidden.png）。因此不能直接用 CSS z-index 实现网页与悬浮面板排序；Windows 局部 SetWindowRgn 原型已在真实窗口验证单个不透明面板露出、洞内按钮命中、露出网页滚动及取消裁剪恢复；证据见 canvas-c01/web/clipping/occlusion-result.json。当前机器系统输入与一次中文输入法候选提交已验证（canvas-c01/web/focus/focus-result.json）；面板/视口/DPI 自动重算、复杂合成及输入法弹窗遮挡仍待验证。基础网页输入/缩放通过不代表此遮挡契约已满足。

覆盖模式由桌面宿主管理。退场只改呈现，保持真实坐标、输入、选择、任务和撤销；退场后释放输入给其他软件。恢复处理显示器及缩放变化，并提供快捷键之外的找回入口。多显示器等行为实测后声明。

C01.1 先确定基础宿主契约和风险边界；C01.2、C01.3、C01.4 分别尽早验证隔离、网页和透明覆盖，并核实共存限制。后续仅依赖所需子任务；影响核心宿主或数据契约的风险仍阻塞相关实现，不能简单延期绕过。发现阻碍记录证据和适配成本，不擅自更换已选底座。

## 8 格式、备份与复用

文档、配置和索引分别有版本；迁移前保留可恢复副本，失败不覆盖原件。未知版本不得“成功打开”后丢字段。工程换位置支持重新定位目录。

备份声明包含哪些原件、工作内容和节点包；只有路径引用不等于完整备份。凭据不进入普通导出。清理工作数据先做引用检查，隐藏对象和缺失扩展的数据不能当垃圾。

复用记录来源 URL、提交、原文件范围、许可证和本地修改，保留许可声明并核对资源。上游升级用固定作品回归编辑、保存恢复和扩展。调研不是运行证据。

### C06 关系连接首轮实现约定

关系连接复用上游 VECTOR 场景节点（不是执行连线），其 pluginData 中 os.canvas/connection 保存 JSON {version:1, source:<业务 UUID>, target:<业务 UUID>}，关联 localNodeId，不使用 FIG 重开后变化的内部 ID。向量几何是可导出的当前显示结果，端点身份是跟随依据；不引入第二套场景树。

首轮默认连接选择顺序中的源对象右边中点与目标左边中点，通过世界矩阵换算到连接父容器坐标；位置随端点事件重算而不新增独立移动撤销项。端点缺失时保留原几何和元数据并提示，撤销恢复身份后重连。不把保存的静态向量称为完整原生 CONNECTOR 支持。

当前仍在 C06 开发：复制身份重映射、页面/容器变换边界、筛选、端点重选和拖拽吸附、标签与折线曲线尚待实现/验证。未知版本数据保留，不自动迁移或删除。


C06 复制的身份边界：编辑器在复制/内部粘贴完成建图且捕获撤销快照前通知一次 nodes-copied。应用为复制实例分配新业务 UUID，再将该次操作内的连接端点映射到副本；只有未复制的端点保持原引用。跨画布也创建新实例身份，不能因为目标画布没有同 UUID 就保留源实例身份。外部格式粘贴需对应通知或明确兼容路径，当前验证范围以 C06 证据为准。


C06 绑定连接的几何由端点锚点决定：对连接自身应用通用移动、旋转、翻转或尺寸变换后，重算并清除连接自身旋转/翻转，保持端点贴合；父容器的世界变换仍参与计算。此规则不等于端点重选或曲线控制点编辑，后者须单独实现。端点位于其他页面时连接暂时隐藏，返回原页面后恢复，不按端点缺失处理。


C06 锚点扩展：version=1 关系元数据允许可选 sourceAnchor/targetAnchor，枚举 top/right/bottom/left，表示对象局部边界中点。旧数据缺省仍为源右、目标左；未知枚举不按有效关系重算，保留原元数据。属性变更走同一编辑器撤销历史，世界矩阵负责祖先和对象旋转。当前面板支持选择边，不等于拖拽端点、替换目标或自由锚点已经实现。


C06 拖拽端点首轮：选中关系连接显示两个端点手柄，使用实际 drawnView 的缩放/平移定位；在当前页可见、非锁定、非关系对象的四侧中点中，以 14 CSS 像素寻找最近吸附点。拖动期间仅更新展示手柄，松手命中后以一次撤销项更新端点 UUID 及锚点侧；空白处松手或取消保持原元数据。Esc 沿用编辑器取消选中行为。细分可见性（裁剪/遮挡）、并发修改与指针中断需后续完善，不据此宣称完整拖拽验收。


C06 吸附可见性补充：候选锚点必须位于各祖先 clipsContent 的局部范围内，透明度为零的分支不参与候选；锚点的实际 DOM 顶层必须是当前画布（忽略拖拽手柄层），面板遮挡不吸附。此规则不代表已完成场景内所有图形的遮挡判定。


C06 线形：关系 version=1 新增可选 route=straight/elbow/curve，缺省 straight；非法枚举不重算。几何仍为 VECTOR，折线在连接父容器坐标中采用中间 X 的三段路径，曲线采用两端及中间 X 切线生成三次贝塞尔。端点仍由锚点决定，线形通过同一元数据编辑历史修改；不引入 DOM 线条，不宣称支持障碍避让、自由控制点或锚点法向自动布线。


C06 标签首轮：关系元数据增加可选 label 字符串；对应真实 TEXT 子节点以 os.canvas/connectionLabel=1 标记、锁定直接编辑，通过关系面板修改。标签内容以关系元数据为准，当前水平居中于连线局部包围盒、垂直放在整个路径范围上方，留出至少 6 的间距并计入粗描边、宽 240；空标签隐藏子节点而保留身份，复制/删除继承父子树语义。字体使用宿主 ensureGraphFonts 加载，“应用标签”等待字体任务后结束。文本导出不依赖 DOM 覆盖层。水平/垂直短线导出范围、多行布局及外部 FIG 标签往返仍需专项验证。


C06 标签文字编辑后，字体就绪时通过 layoutAuthoredNodes 测量自适应高度，再由连接同步重新定位；水平短线的导出范围包含溢出的文字子节点。当前已验证固定宽 240 的多行中英文，尚未开放自定义标签宽度或字号。


C06 标签字体异常状态按 SceneGraph 和连接 ID 保存在运行时，不写入作品。关系面板提示失败并允许重新加载，重试清除宿主字体失败缓存、重新布局，不变更标签文本与撤销历史；清空标签解除错误。旧文档或不同文本的迟到异常不影响当前关系。未抛异常的字体替代状态继续由宿主通用字体状态展示。


C06 便签：复用 FRAME+TEXT，FRAME 以 os.canvas/note=1 标记；默认暖白纸面、深色正文、宽 240、最小高度 200、四侧内边距 16。垂直自动布局随正文增高，正文横向拉伸；空白区域沿用自动布局容器的选择和移动规则。创建是一条撤销记录，正文编辑沿用原生文字历史，复制和 FIG 保存复用场景子树。颜色/尺寸的可用交互仍以开发验收为准。

编辑导致的布局变化属于作品编辑，必须更新来源字段标记，使 FIG 导出写入实际尺寸；导入、字体准备等 applyDerivedLayoutDuring 中的计算仍保留原文件来源字段。不能把所有布局计算一律当成导入派生计算，否则打开后再次编辑的自适应容器会导出旧尺寸。该规则不意味着重排所有导入作品。


### C06 网格布局与预览归档
当前 FIG 写入器不原生写入网格布局，以 open-pencil/grid-layout-v1（format 类插件数据）保存 version=1 的轨道、行列间距、布局模式、内距、轴向尺寸与对齐，以及子项 gridPosition。轨道尺寸支持 FIXED/FR/AUTO；子项显式位置使用从 1 开始的行列编号及正整数跨度（与 Yoga 当前承载一致）；历史扩展读取仍容忍 0，新的界面不产生 0。读取校验版本、结构和有限数值；无效扩展不用于渲染，不能把忽略无效数据等同于未来版本兼容已验收。

退出网格后，若场景仍保留轨道，保存当前真实模式与配置，避免丢失闲置轨道或复活旧 GRID 模式。无网格、无轨道、无子项位置时不写该扩展。此扩展保证我方往返；不宣称外部 Figma 可将其识别为原生网格。外部格式互操作仍按格式专项验收。

预览修改必须在首次写入前通知归档观察者保留原始节点；提交才标记归档变化，取消不发布已提交更新。这是差分 FIG 导出正确比较修改前后数据的前提，不能仅在提交时截取已经被预览修改的节点。实际交付状态见开发现场，轨道和子项编辑能力分别验收。
