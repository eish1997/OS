# 画板嵌入使用说明

日期：2026-10-17。隔离验收已通过；默认仍关闭，避免无资源包时启动失败。未包含正式部署或推送。

## 启动（隔离）

1. 确认工作台静态产物：`output/canvas-workbench-build`（`vite build --outDir output/canvas-workbench-build`）。
2. 确认画板资源包：`.runtime/canvas-workbench-package-090`（或仓库外复制后的同结构目录）。
3. 在独立数据目录配置：

```
CANVAS_ENABLED=1
CANVAS_PACKAGE_DIR=.runtime/canvas-workbench-package-090
DATA_DIR=<独立样例目录>
WORKBENCH_PASSWORD=<本地密码>
```

4. 使用 Node 24.19.0 启动宿主：`tsx server/index.ts`（本机可用 `%USERPROFILE%/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`）。
5. 浏览器打开工作台同源地址；底层 iframe 为 `/canvas/`，API 经 `/api/canvas/` 代理。

## 日常操作

- **项目与画板**：顶部项目切换会先保存当前画板再切换上下文；失败时停留原项目。
- **专注画板**：临时隐藏中层浮窗，退出后恢复，不永久改布局。
- **保存状态**：「布局已保存」与「画板已保存」分开显示。
- **版本冲突**：另一会话已保存时，可重载远端或另存冲突副本。
- **跨标签**：其他标签页保存布局后，本页会提示可重新加载同步；有本地未保存更改时优先另存。
- **容量不足**：画板写入可能返回 507；清理/导出后重试，已保存修订保留。

## 备份与回滚

- 含画板的备份为 schema 2（VACUUM 快照工作区库与场景）；schema 1 仍可校验。
- 关闭嵌入（`CANVAS_ENABLED=0`）只卸视图，不删除作品与绑定。
- 未知 schema（如 3）会被拒绝。
