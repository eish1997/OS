# 088：文件确认与作品包归属

2026-10-16，EMB-04继续。未部署、推送或模型调用。沿用独立临时目录，未操作真实用户服务。

## 实现

文件预览只返回路径和短时令牌，并把令牌记在当前项目上。确认前先看父目录是否已有归属：属于其他项目则不调用原生确认。新目录在确认后预留画板。其他项目不能拿同一令牌完成确认。

作品包上传先解码清单。引用画板已属于其他项目时直接拒绝，不写入导入记录。已有场景必须走显式关联，不能靠上传占用。新画板先预留，再保存原件。继续恢复成功后，用导入操作身份确认修订。打开子目录时，新登记的画板同样预留到当前项目。

## 验证

`tests/canvas-resources.test.ts` 在真实受管子进程上通过：B 不能确认 A 目录中的文件，也不能使用 A 的预览令牌；A 确认新文件后 B 读该目录被拒绝。B 上传指向 A 画板的作品包返回 403。A 上传并恢复后归属为 ready，B 读该场景返回 403。原 `canvas-api` 与传输测试通过，根类型检查通过。
