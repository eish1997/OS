# 063 工作台层级与全局外观

2026-10-15。用户连续要求设置可调整线条与配色，并按新版设计文档优化一轮UI，两项共同实施。

## 实现

- 名称导航208px，可折叠52px；小窗口响应；全局56px顶栏与36px窗口标题分层，保存归入布局菜单。
- 统一16px SVG操作图标，移除首字导航与混杂字符按钮；区域分割工具hover/focus显现，6px分隔线命中区不随外观缩小。
- 无内容时显示空间起步区、真实可用窗口介绍、默认/空白布局选项；不自动替换既有布局或项目。恢复已有窗口后不会在关掉最后一个窗口时突然覆盖编辑区。
- 设置入口在左下角。四套语义token配色、0.5–3px全局边界、导航折叠偏好实时生效并自动保存；提供恢复默认外观。
- schemaVersion1增加可选appearance，旧配置保持兼容；服务端验证主题枚举、半像素步长和范围。外观随现有布局配置、备份和完整导出保存。导入空间/冲突合并保留远端全局外观。
- 合并基础CSS同名规则，尺寸与主题集中定义；焦点环独立，阅读纸面沿用本地阅读模式。

三组真实Chrome验收：原有窗口/资产/聊天烟测、布局压力及恢复矩阵、专用外观测试。外观测试断言3px实际浮窗/弹窗/分隔线计算样式、浅色画布、窗口坐标与输入保持、刷新/新浏览器恢复、四种配色、导航模式持久化和默认恢复。标准入口已纳入 `npm run test:workbench-ui`。

- 3px线宽使自适应工具栏增高4px，导致屏幕浮窗位置改变；固定56px外壳高度，保留控件空间，实际位置断言通过。
- 分区工具改为hover显示后，测试先按真实用户路径hover区域再点击，没有使用force绕过命中检查。
