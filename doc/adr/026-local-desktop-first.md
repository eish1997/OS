# ADR-026 本地电脑版优先

日期：2026-10-07。状态：按用户最新指令采用。所有者：root。

用户明确要求先完成工作台，多端连接以后增加，目前只做本地电脑版。此前部署准备开始挤占核心产品工作，并以未有的手机/云环境阻挡本地阶段验收。

决定：本机主服务＋本机 Pi worker＋本机 SQLite/资产文件＋桌面启动入口为当前交付。M0/M1 在本地推进；手机、远程入口、远程节点、Linux部署、跨机器凭据迁移与异地恢复转入后续 R 阶段，保留需求与真实未验收状态。数据/认证/存储接口保留，已有部署准备不删除，也不继续下载安装部署环境。

本地持久化、权限、模型外发范围、取消/对账、备份恢复、Windows生命周期、实际用户价值不因范围缩减而免验。腾讯组件是独立候选实验，不能用本地 worker 或 QEMU TCG 替代未知代码的隔离；资料研究可先交付，运行证据另记。

具体交付、验收和后续任务见[本地电脑版执行范围](../dev/本地电脑版执行范围.md)。本决策覆盖主文档/执行文档旧的当前多端前置；迭代历史事实保持，不将延期当作测试通过。本轮由主 Agent 复核，没有新增子 Agent 审查。
