# 对话窗口布局 v2（默认态）

日期：2026-10-22。状态：**已实施**（`CHAT_UI_DESIGN.version=2026-10-22-layout-v2`）。  
依据：用户对当前界面的反馈；Claude / Cursor Agent / Codex 的聊天骨架（抄结构，不抄品牌皮）；[交互审查线框](../reviews/对话窗口交互审查与产品参考-2026-10-21.md) §窗口如何分区。

本页只钉**信息架构与默认可见面**。字号、命中、滚动锚点、IME、纯图、发送键等可测契约仍以 [chat-ui-design-freeze](chat-ui-design-freeze.md) 与 `shared/chat-ui-design.ts` 为准；冲突时：**默认外露控件以本文为准**，行为契约以冻结文为准。

## 1 抄什么

| 来源 | 抄 |
| --- | --- |
| Claude | 主区几乎只有对话；底部一张 Composer 卡（`+` / 正文 / 模型·档位 / 发送） |
| Cursor Agent | 顶栏极简；工具过程默认可紧凑；`⋯` 收纳低频动作 |
| Codex | 结果优先：过程不当说明书铺在脸上 |

不抄：营销大字空状态、紫光/毛玻璃、把工作台改成单栏聊天站。

## 2 默认看见什么

```text
┌─ 话题名 ▾     🔍   ⋯ / 聚焦 ─────────────┐
│                                           │
│   消息流（唯一主滚动）                      │
│   · 用户 / Pi 角色清楚                      │
│   · 工具：默认一行摘要，点开再详              │
│   · 消息操作：悬停或聚焦后出现                │
│                                           │
├─ 活动带（无活动则整带不占位）────────────────┤
│  运行中 / 待答 / 排队摘要；停止始终可达         │
│  ┌ Composer ───────────────────────────┐  │
│  │ 附件芯片                               │  │
│  │ 多行输入                               │  │
│  │ ＋附件   模型·思考·时长        发送/停止 │  │
│  └────────────────────────────────────┘  │
└───────────────────────────────────────────┘
```

| 区域 | 默认 | 说明 |
| --- | --- | --- |
| 顶栏 | 话题名（可切换）、查找、`⋯`、必要时「聚焦对话」 | 不长期展示模型全文、额度长句、功能说明书 |
| 主消息区 | 对话正文 | 仍是唯一主要纵向滚动面 |
| 消息操作 | 悬停/键盘聚焦后出现 | 复制、引用、编辑重发、从此分支、定位执行仍保留 |
| 活动带 | 有开放 Run / 待答才出现 | 不得再被「只显示最近几条」裁掉停止/待答 |
| Composer | 一张输入卡 | 附件、下次模型/思考/时长、主发送在卡沿；快捷键提示弱化或悬停可见 |
| `⋯` 菜单 | 改名、新建话题、分支/来源、导入导出、压缩、下次配置与额度 | 能力不删，只改入口 |

## 3 明确收起（当前痛点）

下列内容**不得**在默认首屏整排外露：

- 「改名 / 新建话题 / 查找 / 分支/来源 / 导入导出 / 压缩入口」字链横条  
- 分支、压缩、导入的说明长段落  
- 「切换话题」「筛选话题」双控件并排占满（改为话题名 ▾ 与查找；筛选可进查找面板）  
- 每条消息下常驻五连字链  
- 输入区上方常驻长额度/限制说明书（改为弱提示或点进额度）

## 4 不改范围

- 不删 Pi 能力：分支、压缩、导入导出、指导/排队、工具过程、恢复与额度仍可达。  
- 不改三层工作台、项目切换、窗口停靠/浮窗契约。  
- 不在本轮重做主题色体系；沿用工作台既有 token。  
- 不要求像素级复刻任一竞品。

## 5 怎么算过

实施后用隔离或日常入口对照截图，满足：

1. 默认首屏可一眼找到：当前话题、最近消息、输入框、发送。  
2. `⋯`（或等价菜单）内能到达：改名、新建、分支/来源、导入导出、压缩、配置与额度。  
3. 消息操作在悬停/聚焦下仍可完成复制与引用；窄窗不丢发送与停止。  
4. 待答 + 多条排队时，停止与确认入口仍在（既有活动 Run 规则不变）。  
5. 冻结文中的字号/命中/消息区比例/IME/纯图/发送键仍成立；若选择器变更，更新对应浏览器脚本选择器，不降契约。
