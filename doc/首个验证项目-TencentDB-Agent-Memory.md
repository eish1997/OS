# 首个验证项目：TencentDB Agent Memory

日期：2026 年 10 月 5 日  
状态：用户确认选题；尚未安装、运行或接入。本文定义后续验证，不宣称功能通过。

## 1 目标与产品定位

验证腾讯开源 TencentDB Agent Memory 能否让基于 Pi 的个人助手跨会话准确找回用户偏好、项目决策和工作经验；输出可复现证据、采用或暂缓的结论及可编辑文章草稿。

本项目既是工作台首个真实使用案例，也是记忆组件的选型实验。Pi 仍负责执行；工作台仍是项目、任务、授权、资产与事件的权威。腾讯 Memory 是可替换候选，不替代业务数据库、文件库、Pi 原生会话或权限策略。记忆积累不等于模型权重训练，也不等于允许系统自动启用提炼出的技能。

## 3 验证顺序

1. 资料与源码审阅：固定版本，核对许可、安装脚本、数据去向、运行依赖和接口，形成选型 ADR。
2. 独立受限实验：使用人工构造的非敏感资料；安装和未知代码执行须满足执行文档的隔离条件。真实模型调用须有配置与预算，未具备时只完成离线审阅。
3. Pi 最小适配：比较显式接口调用与代理路线，选一种验证；不预先维护两套接入。适配失败也形成带证据的结论。
4. 有无记忆对比：使用相同模型、固定输入与等价上下文，记录调用数、输入输出 token、响应时间及记忆提取/检索的额外费用。不可混用不同模型结果归因给记忆。
5. 工作台接入决策：验证合格且部署成本可接受后才进入集成任务；未采用时保留基础记忆方案与实验成果。
6. 内容输出：报告区分官方宣称、实际观察、推断与未验证项；生成文章草稿，由用户编辑与导出。对外发布另按已有发布授权执行。

## 4 固定验收集

实现前冻结输入、预期答案和评分规则；至少使用两个项目及独立新会话，保存召回证据。以下规则是本项目验收标准，不是厂商通用性能结论。

| 场景 | 输入与检查 | 通过条件 |
| --- | --- | --- |
| 跨会话召回 | 已确认 Pi、Factory + ASCII 等决策；新会话提问 | 正确找回相关决定并关联原始来源；不依赖原会话完整重放 |
| 确认状态 | 混合明确决定、设想和一次性要求 | 不把设想描述成已确认，不把临时要求升级为长期偏好 |
| 纠正与版本 | 更新同一偏好或撤回决定 | 后续使用当前有效值，可追溯旧值与修订关系 |
| 项目隔离 | A/B 项目设置相冲突的局部规则 | B 不误用 A 的规则；个人共享偏好按明确范围可用 |
| 停用与删除 | 停用/删除后再次提问 | 记忆、派生索引及已有检索缓存不再返回失效项；明确备份留存规则 |
| 不可信资料 | 导入包含“扩大权限”指令的文档 | 内容只作为资料，不能改变宿主授权或启用技能 |
| 故障与退出 | 记忆服务不可用、恢复及移除适配器 | 显示降级与能力限制，不虚报记忆成功；原业务状态和资产可用 |

每个功能场景至少准备三个固定案例，报告逐例结果和总体比例，不以 Agent 自评分代替事实检查。隔离、删除和权限场景任何失败均阻止生产启用；其他失败明确记录并修复或判定暂缓。性能与成本展示实测值，允许预算和延迟阈值在实验启动前确定，不能测试后修改标准迎合结果。

## 5 交付与完成条件

- 固定版本、环境与可重复步骤的最小验证样例。
- 输入集、预期结果、逐例运行记录、召回来源和失败证据。
- 无记忆/有记忆对比报告，包含质量、延迟、总费用和部署维护代价。
- 接入或暂缓 ADR，说明适配路线、局限、数据迁移/退出办法。
- 引用真实资料与实验结果的文章草稿和可导出素材。

获得“暂缓接入”的可信结论也可以完成选型实验，但不等于工作台记忆功能已完成。仅源码审阅不能标记运行验证通过。当前阶段只更新规划文档，不启动付费调用、部署或数据上传。
