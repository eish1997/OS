# 对话窗口使用说明

面向工作台内的 **Pi 对话** 浮窗/停靠窗。布局默认态见 [layout-v2](chat-ui-layout-v2.md)（话题 + 消息 + Composer；低频能力进 `⋯`）。候选 `output/chat-ui-build`；CHAT-16 曾应用到日常 `F:\AI\OS\dist`——**layout-v2 代码改动后须重新构建/应用才进日常**。契约见 [设计冻结](chat-ui-design-freeze.md)。

## 打开对话窗

1. 在工具栏点击 **「＋ 窗口」**，选择 **「Pi 对话」**（正常用户路径；不要用布局 fixture 代替验收）。
2. 需要第二窗时再次 **「＋ 窗口」→「Pi 对话」**；默认可停靠到空叶，同话题多窗互不覆盖草稿。
3. 顶栏 **「聚焦对话」** 可放大当前聊天，不静默重排你已保存的布局。

## 话题与历史

| 操作 | 入口 |
| --- | --- |
| 切换话题 | 顶栏话题下拉（话题名 ▾） |
| 查找本话题 | 顶栏「查找」；可取消 |
| 新建 / 改名 / 筛选 / 分支 / 导入导出 / 压缩 / 全部执行历史 | 顶栏 **⋯** 菜单 |
| 深历史 | 主消息区滚动加载；`⋯` →「全部执行历史」 |

## 输入、发送与运行中

- **Enter** 换行；**Ctrl/Meta+Enter** 执行当前主按钮（发送 / 排队追问 / 指导，与单选一致）。
- 中文输入法**候选确认**不会误提交；组合输入期间请用候选窗选字后再发送。
- 运行中可选 **排队追问** 或 **指导**（有附件时指导不可用）；**停止**始终在活动区可达，不会被「只显示最近几条」裁掉。
- 纯图片不能单独发送：需附带文字；原因会在界面明示。
- 图片入口：选图、粘贴、拖入；也可从资产浏览附加到**指定**聊天。

## 连接与下次配置

- 未就绪时 Composer 下提示 **「打开连接设置」**；完成后返回**原话题**，草稿保留。
- 已就绪时用 Composer 上的 **「下次配置与额度」**（或 `⋯` 内同名项）调整思考强度、时长等；旧 Run 上可见 **「本次冻结」** 摘要。
- 订阅与 API 额度分开：ChatGPT 订阅不展示 API 费用预算，也不会在断开后自动改用 API。接近上限时输入区上方有短提示。

## 消息与版本操作

| 能力 | 说明 |
| --- | --- |
| 复制 / 选文引用 | 悬停或聚焦消息后出现操作；代码块可复制；选文可引用回输入框 |
| 本轮工具过程 | 按轮展开；与「全部历史」配合查看早期失败 |
| 从此分支 | 话题菜单 / 消息入口；可返回来源 |
| 编辑重发 | 默认可继承附件并勾选保留/移除；独立副本，不改原件 |
| 重新生成 | 在工具结果安全基点上重生答案，不默认重做已成功工具 |
| 压缩 / 导入导出 | 话题菜单可达；原件保留；导入后可切换话题重开 |

## 窗口、主题与画板层

- 停靠、浮窗、收起图标后再展开：草稿与附件应恢复。
- 主题与线宽随工作台外观；窄窗与缩放下保持可读字号与可点目标（见设计冻结）。
- 画板三层：留白可穿透，浮窗不透明；真画板 iframe 挂载仍属嵌入前置，默认可能关闭。

## 断线、备份与候选身份

- 服务短暂不可用时界面应显示重连/错误，**不**假空历史；恢复后旧记录仍可读。
- 普通备份 **不含** 凭据；干净目录还原后业务记录可读，凭据需另行配置。
- 核对身份：构建产物 `output/chat-ui-build`，证据根 `output/dev-evidence/chat-ui/loop-001/`。日常回退：停服务 → 用 `AI-OS-Backups\chat16-20261022-112312\dist` 覆盖 `F:\AI\OS\dist` → 再启动（见 `chat16-report.json`）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 主按钮灰色 | 模型未就绪、纯图无字、或提交前限制命中；打开连接/下次配置或补文字 |
| 待答/停止找不到 | 看活动区全部开放 Run，勿只翻历史卡片 |
| 粘贴图片无反应 | 确认焦点在「对话输入」；系统剪贴板需位图；非图会提示仅支持图片 |
| 指导不可选 | 当前有附件时按设计禁用指导，可改排队或先移除附件 |
| 想回退旧 dist | 按 `chat16-report.json` 的 rollback 步骤恢复备份包后重启 |
