# 对话窗口设计冻结（CHAT-02）

日期：2026-10-21（layout-v2 外露面 2026-10-22）。常量源码：`shared/chat-ui-design.ts`。版本标识：`2026-10-22-layout-v2`。

本文件冻结第 3.1 节可测标准与首版行为，供 CHAT-03–14 实施与 CHV 验收引用。调整须改常量、更新本文并重验受影响场景。

**默认可见面（2026-10-22）**：外露控件与菜单收纳以 [chat-ui-layout-v2](chat-ui-layout-v2.md) 为准；本文继续约束字号、命中、滚动、IME、纯图与发送键。layout-v2 实施后需 bump 版本标识并重验受影响选择器。

## 分区

| 区域 | 职责 | 排除 |
| --- | --- | --- |
| 标题栏 | 话题名/切换、查找、`⋯` 菜单；必要时聚焦 | 功能字链横条、说明书段落、诊断堆叠（见 layout-v2） |
| 主消息区 | 唯一主要纵向滚动面 | 多滚动框争抢关键操作 |
| 活动/待答区 | 全部开放 Run；停止与待答不可被历史裁剪 | `slice(-3)` 决定活动是否存在 |
| 输入区 | Composer 卡：正文、附件、下次模型档位、明确发送 | 已上传/已发送/已确认混态 |
| 按需详情 | 工具、额度、恢复；消息操作默认悬停出现 | 全部塞进「模型请求」唯一入口；消息五连字链常驻 |

## 尺寸与字号（浏览器 100%）

工作台仍有 `html{zoom:.75}`。聊天窗用局部 CSS 变量补偿，使**视觉**字号达标，不以 CSS 字面 14px 冒充。

| 项 | 视觉目标 | CSS（zoom=0.75） |
| --- | --- | --- |
| 正文 | 14px | `calc(14px / .75)` |
| 控件/文件名 | ≥13px | `calc(13px / .75)` |
| 辅助 | 12px | `calc(12px / .75)` |
| 指针命中 | ≥32px | `min-height: calc(32px / .75)` |
| 触控 | ≥44px | CHAT-13 实测；首版指针先达标 |

## 主区与断点

| 项 | 冻结值 |
| --- | --- |
| 默认放置 | `preferredEmptyLeaf`：最大空叶；并列取更右、更下。不改写已有手动布局 |
| 1366×900 新空间 | 默认树中间叶约 60% 宽；优先落入该叶，视觉主聊天区目标 ≥640px |
| 窄容器 | 聊天容器视觉宽 &lt;420px 为窄；收起次要详情，不缩字号低于上表 |
| 无法容纳 | 提供「聚焦对话」入口（CHAT-04 完成浮层/放大行为）；不静默重排用户布局 |

## 输入与消息空间

| 项 | 冻结值 |
| --- | --- |
| 初始行数 | 3 |
| 自动增高上限 | 12 行后内部滚动 |
| 展开编辑 | 「展开编辑」/「还原输入」；展开后输入区最多约占窗高 70% |
| 800×600 | 消息区高度 ≥ 聊天窗 40%（`min-height: 40cqh`） |

## 滚动锚点

用同一 `data-message-id` 消息元素相对 `.wb-chat-history` 视口的偏移验证；容差 **8px**。不只断言 `scrollTop`。

## 发送与换行

| 键 | 行为 |
| --- | --- |
| Enter | 换行 |
| Ctrl/Meta+Enter | 执行当前明确主按钮动作（空闲发送 / 运行中与 radiogroup 所选排队或指导一致） |
| 指导/排队 | 运行中 radiogroup 选择；主按钮文案与 Ctrl/Meta+Enter 一致；有附件时指导不可选 |
| IME | `isComposing` 或 `keyCode===229` 不提交；系统 IME 实测归 CHAT-13/14 |
