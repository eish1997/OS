# 本地电脑版执行范围

日期：2026-10-07。用户最新指令：“我们先把工作台做好，多端连接放到后面再加……目前就做本地电脑版”。本文件与 [ADR-026](../adr/026-local-desktop-first.md)明确覆盖此前把手机、云部署作为当前 M0 前置的要求；长期愿景仍保留。

## 当前产品

在这台 Windows 电脑使用个人 AI 工作台。桌面入口一键打开，独立本机后台负责 Pi 执行、状态和文件；页面通过回环 API 访问。现有 ChatGPT 连接沿用，默认配置服务于日常使用。电脑需要联网调用模型，“本地电脑版”不表示离线模型。

- 首页项目画廊、独立项目标签页、项目和选中资料/草稿的上下文对话；当前草稿对话修改已有051工程与真实Pi证据，完整交互待验收。
- 目标转任务、真实 Pi 执行、过程与成果同步、取消和中断后对账接续。
- 本地文件/资产库、版本与来源、上传、搜索、预览、整理与导出。
- 有来源的记忆和项目摘要，成果转成文章草稿并编辑导出。
- 本地持久化、后台运行、自动备份、可验证恢复；Factory + ASCII 界面与清楚的保存/运行状态。

先完成本地 M0 单任务体验，再推进本地 M1 两 worker、一层委派及可卸载插件。当前已有本机网页和桌面启动入口，尚未打包成独立安装程序；核心体验稳定后再评估 Electron 包装，不为当前使用新增服务器配置步骤。

## 数据与执行

SQLite 由一个本机主服务写入；资产文件、原生会话、索引和备份放在本机受保护目录。凭据与业务资料分离，普通恢复包排除凭据。模型请求仍按授权外发，原有权限、预算、版本与来源检查保持。

关闭页面不等于停止后台任务；电脑关机或睡眠会影响执行，恢复必须对账，不承诺全天在线。独立 worker 或工作目录不能代替 OS 隔离；060按用户指令恢复Pi原生文件和命令工具，支持授权的本地开发、依赖安装和测试；外部资料不授予执行权限，第三方可执行插件仍独立审阅。普通工作目录文件不自动成为受管理资产。

## 部署准备纠正

QEMU TCG 仅适用于可信 Linux 部署预演，不能作为未知代码的安全隔离边界，guest 内存配置也不是宿主内存硬上限。依据 [QEMU 官方安全说明](https://www.qemu.org/docs/master/system/security.html)与已保存的 [v11.1.2 原文](../../output/dev-evidence/qemu-11.1.2-security.rst)。腾讯实验仍需满足受支持的隔离方案及实际边界验证。

本轮调整前已下载、校验并在开发私有缓存解压便携 MSYS2，验证 GPG/Pacman 版本与归档签名；仅开发工具准备，未安装 QEMU、下载 Ubuntu、启动虚拟机或运行腾讯代码。缓存不进入业务资产和普通恢复包。详细事实见[045](iterations/045-local-desktop-first.md)。
