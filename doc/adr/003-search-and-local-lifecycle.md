# ADR-003：资产搜索与本地后台生命周期

日期：2026-10-06。状态：本地实现与验证通过，远程部署验收未完成。

后续落实：整体/分项应用写入限制、SQLite主文件页上限和恢复空间已在[ADR-004](004-storage-admission.md)实现；以下“整体硬配额待落实”指当时状态及仍待部署验证的物理边界。

资产文件和业务实体仍为权威。SQLite 增加可重建的搜索表，按项目、名称、标签、UTF-8 文本做字面子串检索；中文可用，无外部向量服务或模型费用。单文件现有10 MB上限；不截取前100 KB作为“全文”。无法解码的内容及图片、PDF、DOCX只检索名称和标签，未声称解析这些格式。

名称与标签使用revision保护，不改变文件身份、版本或哈希。资产登记/删除/恢复和索引事务一致，读取片段重新核对原文件哈希；损坏索引不作为实际原文返回。恢复后索引可从资产重建。工具与界面走同一宿主业务接口，工具限当前项目，搜索分页限制响应量。来源读取与索引重建成本随资料量增加；当前方案尚未做大规模性能验收。

界面以版本化本机视图缓存保留每个项目的页签、搜索和选中文件。不存在、删除或跨项目的选择不恢复；没有保存任意可执行页面或代码。手机查找/预览默认收起输入区，避免遮住内容。

本地产品服务采用Windows隐藏进程启动，独立于启动终端。`.runtime`身份记录含PID、创建时间、Node程序、cwd、入口、启动标记、实例/健康地址和所有者；密码不进入参数或记录。停止前核对Win32进程与HTTP实例，再认证请求正常退出。PID重用或身份不符不强停；停止成功记录结束身份。Windows PowerShell5与当前PowerShell7均验证身份读取，修正了Cookie发送差异及JSON日期解析差异。

这不是远程常驻服务、系统安装或开机自启。主机重启、睡眠、真实模型任务继续及受监督恢复仍需部署与真实调用证据。设置/诊断提供只读空间测量，跳过符号链接且报告测量缺失；资产500 MB上限仅限原文件。数据库、索引、会话、日志和工作目录的整体硬配额、备份容量与保留周期须结合部署环境落实，不能把用量展示当作全盘配额验收。

证据：[工程基线](../../output/dev-evidence/verification/report.json)、[搜索交互](../../output/dev-evidence/ui/search-interactions.json)、[迭代003](../dev/iterations/003-search-and-lifecycle.md)。原文件/回收站/恢复测试用受控临时资料；没有执行未知代码或调用模型。
