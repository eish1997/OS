# 主开发文档整合审查结论

审查日期：2026 年 10 月 5 日。五个子 Agent 分别完成产品、Pi 集成、数据、自我升级和调度审查，主 Agent 已整合至主开发文档 v0.2。未安装 Pi，未运行代码测试。

## 核心结论

v0.1 已准确记录愿景和产品形态，但不足以直接驱动可靠实现。主要缺口是缺少首版价值闭环，以及生命周期、状态、权限和发布恢复的可执行契约。Pi 选型保留。

## 已采纳修订

| 类别 | 发现 | 整合处理 |
| --- | --- | --- |
| 产品 | 缺固定场景，输出推迟 | M0 加入真实成果、可追溯文章草稿与导出 |
| 体验 | 记忆与标签归属不明确 | 定义记忆范围、上下文冻结、后台归属与快速任务 |
| Pi | 原 MCP 信息过时 | 官方 SDK 已描述支持；按固定版本先验证，再评估社区 adapter |
| 执行 | 会话、Run 与进程混用 | 明确 SessionBinding、完成信号与业务验收 |
| 数据 | 文件和数据库一致性缺失 | 不可变资产版本、持久操作日志与启动对账 |
| 恢复 | 代码回退不保证数据恢复 | 迁移分类、兼容与恢复证据，首个插件无迁移 |
| 并行 | 缺调度权威与预算继承 | 单机唯一调度、租约、受控 worker、预占与结构化交接 |
| 权限 | 目录隔离被误当执行隔离 | 区分逻辑与 OS 边界，版本授权、生产资源白名单 |
| 升级 | 缺构建、评价与激活协议 | manifest、固定评价、发布状态机、版本切换与观察 |
| 验收 | 只验证功能，缺故障场景 | 追加中断、重放、副作用未知、权限和备份恢复剧本 |

## 首版范围收敛

M0：Pi 单执行 worker、固定项目页、真实资产、状态同步、故障识别、文章草稿与导出。

M1：两个 worker 受控并行、一次只读图片对比插件升级，界面和 Agent 使用同一操作，验证启用与恢复。

长期动态界面、机会监控、多平台发布、复杂群组和自动内核优化保留为后续方向。

## 暂不直接采纳为既定决策

具体 SDK/RPC、原生 Windows/WSL、数据库、沙箱产品、模型、社区扩展和真实业务项目未定。并发数与委派深度为建议默认值。不得把这些写成用户已确认技术选型。

首次插件可只读产生视图，但仍必须处理真实资产，并可通过界面和工具调用。研究案例的能力不能外推为已实现的通用自我进化。

## 开发开始前要交付

1. 固定 Pi 与依赖版本的清单。
2. SDK/RPC 和执行宿主技术决策记录。
3. 命令、事件、状态机和会话映射契约。
4. 一个 M0 最小程序及真实验收证据。
5. 能力与环境权限边界说明及测试结果。
