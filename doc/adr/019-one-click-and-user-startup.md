# ADR-019：一键打开与当前用户自动启动

2026-10-06，当前电脑已启用；沿用[后台守护](018-owned-service-supervision.md)。

## 选择

创建桌面“打开工作台”快捷方式：隐藏启动后台守护，复用现有健康工作台，确认服务身份和127.0.0.1地址后才请求默认浏览器打开。已有后台进程不重复创建，打开失败时保留数据与进程并显示简短提示。首次使用新浏览器仍需已有工作台登录；不会取消认证或从其他浏览器复制会话。

当前用户Startup目录内放置另一个隐藏快捷方式，登录Windows时只启动后台、不弹出浏览器。无需管理员权限、计划任务密码或系统Node安装；仍使用已存在的Node24。桌面入口打开浏览器和后台启动是两个动作，后台启动不消耗模型额度。

生成的快捷方式带工作区/名称哈希和用途说明；创建、状态和移除都检查目标程序、完整参数、工作目录、说明与窗口模式。同名的其他程序快捷方式拒绝覆盖或删除。只操作明确的两个文件，不递归清理用户桌面或Startup目录。

PowerShell5使用UTF-8 BOM读取包含中文的脚本，入口JSON显式输出UTF-8，防止中文路径在Node调用方损坏。守护自身退出过程中也复查实际CIM；残缺信息不能直接当作仍存活的外来进程，仍存活的不匹配身份继续拒绝。

## 证据与边界

[028](../dev/iterations/028-one-click-and-user-startup.md)记录103项完整工程验证、真实快捷方式的保存与命令调用，以及产品连接/文件/登录/用量/备份保持。

测试在独立中文目录生成真实.lnk，执行其实际保存的启动命令和打开命令；打开命令加NoBrowser以避免干扰现有浏览器。实际当前用户Startup已配置，保存的命令已执行退出0，但没有以重启/注销电脑来验证真实Windows登录，也没有观察默认浏览器的新页面。这些未验收项明确保留，不能用快捷方式记录代替OS事件或浏览器画面。

本轮是本机方便使用的入口，不是Electron安装包、全天在线服务器、睡眠唤醒或真实手机跨网络验收。关闭浏览器不停止后台；退出Windows、睡眠或关机会影响本机服务，远程常在线主服务仍按原目标推进。
