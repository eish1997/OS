# Pi 能力使用说明大纲（交付用）

2026-10-20。正式交付前随候选版本再核对一遍入口与数据摘要。本文件先固定用户必须知道的边界。

## 运行结束与验收完成

- **运行结束：** 一次任务进入 completed / failed / cancelled / interrupted，历史可查看。
- **验收完成：** 计划中的 PIV 项有当前候选证据，且主界面可完成设置、启动、观察、纠正、交互、停止与恢复。二者不是同一回事。

## 额度、时间与等待

- 新任务受请求次数与费用额度限制；追加额度后继续仍计入同一任务。
- 「长任务」最多约 30 分钟；「模型无响应上限」与「用户答复等待上限」分开计时，先到的生效。
- 插件问题到期不会自动同意。

## 不支持的终端能力（PIV-12）

网页工作台**不提供**下列能力，页面上也没有假装已接通的开关：

- 终端自定义组件（`custom`）与多行终端编辑器（`editor`）
- 终端主题、布局像素复刻、终端快捷键与 `externalEditor`
- 插件命令上下文中的 `newSession` / `fork` / `navigateTree` / `switchSession` / `reload`（会明确拒绝，不会静默成功）

工作台自己的「从历史节点开新话题」是宿主分支能力，不是上述 SDK 终端动作。

插件管理里主题资源显示为「网页不支持」，无法勾选启用。

## 配置与 MCP

- 可预览并确认导入原版 `settings.json`：思考档位、同提供商模型、按模型档位、模型名单、已存在的本地技能/模板。不改原文件，不读 `auth.json`，不安装扩展或 npm/git 包。
- MCP 需要登录时只给出授权地址，不自动打开浏览器；令牌只在本机私有文件。
- 「MCP 当前传输」是本次执行观察到的状态，不是常驻原生连接面板。

## 进程与恢复

强停只结束本次执行启动记录里、且创建时间仍相符的进程。创建时间对不上或从未由本次执行启动的进程不会被结束，需自行在系统里确认。摘要复制时会去掉仍含已删除记忆关键词的转述；纯同义词且无共享词无法识别，不要把机密写进可能被摘要的正文。

## 备份与回退

代码、配置、数据分别恢复；不能把代码回退当成数据回滚。应用前检查在途运行、等待交互和 MCP/插件进程。

部署步骤、迁移核对与分层回退清单见 `pi-deploy-checklist.md`（当前会话无部署授权时只准备、不复制到约定目录）。

## 模型额度（本轮对照）

- 宿主按 Pi 目录 USD 记账（`PI_BUDGET_USD`），不等于供应商人民币账单；账单未知项须单列。
- 外部调用总顶与单次脚本上限分开：累计达到总顶后停止新请求，不得每个脚本再从 20 次重新起算。
- 长任务 hold 空等只证明墙钟与会话保留，不证明模型+工具已跨过旧 5 分钟时限。
