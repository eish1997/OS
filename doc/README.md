# OS 重构文档入口

更新：2026-10-15。当前方向：以 OpenPencil 为底座，先独立开发本机画布式资产管理器，再作为重构 OS 的核心。

## 必需的四份文档

| 文档 | 回答的问题 | 何时更新 |
| --- | --- | --- |
| [需求与验收](全能画布需求文档.md) | 做什么、用户怎样使用、怎样算符合需求 | 产品行为或范围变化 |
| [架构与数据约定](全能画布架构与数据约定.md) | 数据归谁、模块怎样协作、如何保存恢复 | 边界、协议或格式改变 |
| [开发执行文档](开发执行文档.md) | agent 按什么顺序循环推进、怎样验证与交付 | 依赖或执行规则变化 |
| [开发现场](dev/current.md) | 实际做到哪里、证据是什么、接下来做什么 | 每轮完成、暂停或受阻 |

四份各管一件事。执行文档定义任务，现场记录状态，不再维护多套 backlog 和 acceptance 台账。文档目标不等于实现状态。
