# 040：自动备份衔接加密转存

2026-10-07。执行原目标中的部署准备；用户没有现成服务器，尚未授权采购。没有启用真实云桶，也未重启原主服务。

## 已实施

[自动备份](../../../server/automatic-backup.ts)在本机恢复检查通过后，将固定转存UUID写入来源回执并一起提交。待确认副本跳过轮转；确认时原子替换归属/清单匹配的回执，后续备份才可清理。转存错误与本地备份成功分开报告，空间不足停止新增，不删除待转存来源。旧副本未带编号时不自动外发。

后台使用独立offsite-backup租约，由主进程续租；[转存子进程](../../../server/offsite-worker.ts)只读检查租约，失效/停止会取消自有rclone并等实际退出。网络操作不占用scheduler执行租约；一轮失败后等待后续轮询，不在工具内无限重试。

[转存模块](../../../server/offsite-backup.ts)接受固定UUID。先探测加密提交记录，只有明确不存在才允许上传；同ID同清单完整解密读回，不重复创建点或覆盖密文；同ID不同内容拒绝。已有对象按大小跳过后仍通过manifest的SHA256完整验证。网络/认证错误不被当成“远端不存在”。CLI可传入预先保存的固定ID，省略时仍生成随机ID。

自动调用在正常成功/失败后只清理本次创建的暂存，清理前验证父目录、真实路径和全部内容无链接。CLI保留审计材料。硬杀可留下暂存；准入上限会拒绝继续，不能宣称已完成崩溃遗留回收或OS配额。

部署Agent通过三个受保护的环境路径接入，不新增用户参数表或HTTP配置入口。源码中[备份状态页面](../../../src/backup-panel.tsx)分别展示本地成功、转存待确认数量与最近确认。Linux服务/环境模板准备独立状态目录，默认配置仍关闭。[部署入口](../../../deployment/offsite/README.md)

## 实际验证

[三项新增测试](../../../tests/automatic-offsite.test.ts)通过：失败后待确认副本超过保留数仍保留，重启沿用原ID，确认后后续轮转生效；传输挂起期间HTTP可访问且固定离线Agent任务能启动，停止会取消并释放租约；错误清单确认和来源所有者变化都不解除待确认保护。与原自动备份测试合跑14项全部通过。

[实际探针](../../../scripts/probe-automatic-offsite.ts)使用固定Windows rclone和新的私有本地crypt目录，合成资产与原生Pi会话：工具缺失的后台失败保留本机成功；新实例用原ID转存；模拟仅本地确认丢失，重启读回成功且远端所有密文字节不变；不同备份占用旧ID被拒绝，远端字节不变。自动暂存回收，恢复资产/原生JSONL保持原件字节，SDK可重开，登录与模型凭据排除。

[探针记录](../../../output/dev-evidence/automatic-offsite.json)有4个转存后台进程、15个传输进程、2个标准输入辅助进程的退出记录。首次缺工具退出1、两次不存在探测退出3均为预期路径；其余成功步骤退出0。它们不包含所有本机恢复检查进程的PID总数。

完整工程检查与源文件哈希见[收尾审计](../../../output/dev-evidence/automatic-offsite-final-audit.json)。原主实例、自动ChatGPT连接、文章、31个登录指纹、模型用量及本机备份保持；没有模型请求，源码的新功能尚未加载到原主服务。新增页面只有类型/构建验证，未在真实浏览器观察本轮变化。
