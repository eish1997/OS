# 091：子画板打开前的归属确认

2026-10-17，EMB-04 收口这一处登记。未部署、推送或模型调用。

## 实现

打开子文件夹先读取它已经对应的画板，不写目录。该画板属于其他项目时直接拒绝。只有身份一致时才允许把目录路径改到当前文件夹；新建登记只在还没有画板时发生。已有目录被另一个路径再次加入时，不再改写原来的路径。

## 验证

`tests/canvas-resources.test.ts` 通过：B 已登记的子目录，A 不能打开，改名后也不能打开或转记，B 的原路径保持不变。本地文件索引、替换和 HTTP 服务测试通过。
