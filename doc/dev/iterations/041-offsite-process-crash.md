# 041：加密转存的进程中断与暂存归属

2026-10-07。上一轮040属于已验证进展：自动调度、固定ID及丢确认对账实现并通过。本轮继续原完整执行目标，补齐同机进程中断证据与可安全回收的历史暂存；不采购或公开部署，不进入依赖M0的M1。

## 实现与范围

[OffsiteWork](../../../server/offsite-work.ts)绑定工作根目录、随机所有者ID和配置摘要，拒绝认领已有未标记内容。每次尝试记录稳定恢复点ID、操作、可回收标识、宿主PID及传输启动阶段。只有自动upload材料可回收；CLI和recover材料保留。

[转存模块](../../../server/offsite-backup.ts)启动rclone前写launching，spawn后写实际PID，等待真实close后才写idle。模块不再因error事件早于close就立即回收目录。自动重试先核对历史尝试：归属、路径、配置摘要必须匹配，宿主与记录中的传输PID必须明确ESRCH。活进程、权限不确定、launching窗口、损坏/外来记录和链接全部保留，不杀记录PID。清理前再验证目录边界、真实路径和全部内容无链接。

rclone自身增加max-duration 5m与HARD策略，原宿主超时保留。[官方时限](https://rclone.org/docs/)只是配置依据，本轮没有等待5分钟验证退出，也未证明进程正在传输时被硬杀的行为。

工作根目录只适用于单主机、同PID命名空间的本地暂存，不能部署到跨主机共享目录或共享容器卷。模块未验证远程文件系统类型/跨主机身份；保留不确定材料仍可触发容量拒绝，需要Agent诊断。进程检查与文件检查不是抗恶意并发修改的系统沙箱，也不是断电持久性证明。具体约束见[部署入口](../../../deployment/offsite/README.md)。

040的成功/失败CLI证据保持历史；新工作根目录包含归属标记，不再以“目录完全为空”作为正常回收断言。[原自动探针](../../../scripts/probe-automatic-offsite.ts)相应检查只剩所有者标记，未覆写040旧结果。

## 实际检查

[新增两项测试](../../../tests/offsite-work.test.ts)使用自有真实子进程，检查活宿主/活传输保留、实际退出后允许清理、launching不确定/CLI/外来材料保留，以及配置变化、伪造归属、链接和非idle拒绝。与原加密边界测试合跑4项通过。

[实际故障探针](../../../scripts/probe-offsite-crash.ts)及[自有检查点进程](../../../tests/helpers/offsite-crash-process.ts)使用新私有目录、合成资产/原生会话和固定Windows rclone。每个来源先通过真实自动本地备份形成待确认回执，再用生产转存/工作目录模块在三个确定阶段暂停并实际SIGKILL：

| 阶段 | 中断时事实 | 新进程检查 |
| --- | --- | --- |
| stage | 暂存记录落地，未开始rclone | 回收已退出的自有暂存，以原ID上传 |
| data | 上传步骤退出，尚无提交记录 | 原ID继续，已有密文字节保持，最后完成提交 |
| commit | 提交步骤退出，尚未本地确认 | 读回既有提交，全部密文字节保持，不重写远端 |

检查点都在传输进程退出后。恢复用真正的自动转存后台进程，来源待确认回执中断时保留，成功后才解除；历史死暂存回收，工作目录仅剩所有者标记。每份恢复资产和原生JSONL与原件字节一致，SDK重开保持会话ID。来源原件字节保持。

[故障记录](../../../output/dev-evidence/offsite-crash.json)有3个强制退出检查点进程、6个后台进程、22个rclone传输和6个辅助进程，共37个记录终态。缺工具退出1、不存在探测退出3是预期；检查点SIGKILL明确记录。计数不包含所有自动本地备份扫描/检查进程。

加密拒绝路径另用当前模块重跑[原加密探针](../../../scripts/probe-offsite-backup.ts)，保留独立[本轮回归结果](../../../output/dev-evidence/offsite-crash-crypt-regression.json)，不覆盖039：14个rclone/辅助进程记录终态，正确恢复/原生会话/额外凭据排除及错密钥、损坏、缺提交、运行中改配置拒绝通过。衍生探针只调整模块相对路径和输出目标，收尾审计核对其来源。

完整工程及当前源文件哈希以[收尾审计](../../../output/dev-evidence/offsite-crash-final-audit.json)为准。原主服务、自动ChatGPT、文章、31登录指纹、用量和本机备份保持；零模型请求，新转存/暂存源码未加载到原主服务。
