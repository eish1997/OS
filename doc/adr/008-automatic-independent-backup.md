# ADR-008：内置空闲备份与自有恢复点保留

2026-10-06。按用户免配置使用偏好，把已验证的独立硬盘备份接入产品维护循环。使用已有联合备份/恢复实现，不引入新数据库、代理或系统计划任务。

019更新：主线程/整段写入锁执行方式已由[ADR-010](010-background-backup.md)替代为只读快照与独立后台维护；下文同步机制保留为016历史设计。故障域、恢复检查、自有保留和容量保护继续有效。

默认每24小时到期，检查间隔60秒；启动后检查一次，服务关闭时取消定时器。无在途或等待任务、所属worker、未对账中断、started/unknown操作时，才在调度租约和存储写入锁下生成一致快照。租约不匹配则等待，绝不取消任务或重放操作。产品进程未运行时不执行备份；开机自启/守护服务仍属部署验收。

当前Windows自动识别已有、来源标记匹配的用户专用AI-OS-Backups目录；Get-Partition核对不同物理硬盘，不能把同盘两个分区当独立存储。显式BACKUP_DIR可用于新独立卷，但同样验证故障域、无链接及归属。未标记的既有目录不会被接管。目录DACL仅当前用户；Linux默认核对不同dev，特殊挂载可由受信任的部署代码验证，HTTP不能传入验证回调或路径。

副本包含数据库/资产/原生JSONL，排除凭据、旧浏览器/节点令牌。每次先在新临时目录实际恢复，检查SQLite、实体数量、资产哈希和已完成原生会话SDK重开；然后写恢复回执并原子提交副本。失败清理仅限当次自有暂存，无链接校验失败则保留异常内容等待处理。

默认保留最近7个有效恢复点，不承诺恰好7个自然日。只有新副本通过实际恢复后才清理旧副本。保留候选须具备同一自动维护ownerId、同源标记、匹配manifest哈希、完整文件哈希和恢复回执；未知目录、损坏副本、手动备份均保留，不计为有效恢复点。递归删除前验证绝对路径直属自动备份目录、真实路径一致且整棵树无链接。禁止删除根目录、源项目或其他工作台内容。

备份根目录默认8GiB保护上限、磁盘保留12GiB空闲；先为新副本和恢复演练预留空间。空间不足时保留已有副本并报告，不先删除唯一恢复点腾空间。来源metadata保存最后成功时间，重启也核验已提交回执，避免落盘之后状态记录失败导致重复初始化。设置页展示最近备份/恢复检查、到期时间、有效恢复点数量和错误；没有模型参数或确认表单。

当前快照/恢复检查采用同步文件接口，在空闲维护期间会短暂占用事件循环；本机小数据通过，尚未验证大规模数据下的响应时延。生产容量、WAL物理边界、远程权限、异地或独立机器恢复和睡眠唤醒仍须单独验收。当前同机两块硬盘不等于防止整机损坏或异地灾难。
